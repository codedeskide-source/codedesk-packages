HOW TO UPDATE THE GITHUB REPOSITORY ALL AT ONCE

Recommended: GitHub Desktop or Git command line.

1. Extract codedesk-packages-github-ready.zip.
2. Clone codedeskide-source/codedesk-packages.
3. Delete the old repository contents, but do not delete the hidden .git folder.
4. Copy every extracted item into the cloned repository root.
5. Confirm catalog.json is directly in the root.
6. Commit: Populate Code Desk 0.1.3 package repository
7. Push to main.
8. Wait about one minute.
9. Run:
   python tools/verify_github_downloads.py

Uploading the ZIP itself to GitHub will not extract it.
