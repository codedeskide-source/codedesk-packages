CODE DESK OFFICIAL PACKAGE REPOSITORY TERMS — VERSION 1.0

The official repository provides Code Desk package metadata and downloadable
package archives. Java, Python, HTML, and CSS are built into the main Code Desk
application. Repository entries for those languages are used only for updates,
repair, rollback, and access to older compatible versions.

Packages must be validated before activation. A failed installation must not
leave a partial active package.
