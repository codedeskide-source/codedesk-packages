CODEDESK 3D VIEWERS 1.0.0
=========================

This optional resource enables the Resources > 3D Viewers menu and preview
routes for OBJ, glTF, GLB, .cdmodel, .cdskel, and .cdanim files.

It does not install a 3D editor. Model, skeleton, and animation editing tools
are reserved for a later add-on before CodeDesk 1.0.0.
